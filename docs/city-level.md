# OB_CityHill: a steep San Francisco street from a MuJoCo course

`Content/Maps/OB_CityHill.umap` is a blog-render level. The scripts in `tools/city/` generate it from an
authored MuJoCo course: one steep city street that goes down a 15 % grade, across a flat block (an
intersection with a cross street), and up a 12 % grade. The look is late-afternoon golden hour. The
level computes no physics: the board pose comes only from the replay file (ADR-0009).

This level is separate from the playable City Park level `OB_City`: it has its own map and folder
(`OB_CityHill`, `/Game/CityHill/`). It does NOT use City Park and never opens the City Park "Showcase"
sublevel. The builder makes a fresh blank map from `OB_Main`.

## Build and render

```
tools/city/build_city.sh <course_dir> [track.npz]        # about 10 minutes
tools/city/render_city.sh Look                           # a fast 960x540 look frame per shot
tools/city/render_city.sh Still                          # one 1080p still per shot
tools/city/render_city.sh Final                          # 1080p, the whole shot
```

- `<course_dir>` is an overboard-viz carve-lab course directory, for example
  `.../overboard-viz/out/carve-lab/data/courses/city_hill`.
- Without `track.npz` the script makes a PLACEHOLDER track (`tools/trail/gen_track.py`): a straight
  run down the street centre at 3 m/s, on the course surface. Give the MuJoCo run as the second
  argument when it exists (`city_hill/kin_track.npz`).
- Work files go to `/tmp/ob-city/`. Stills go to `/tmp/ob-city/frames/MRQ_<Q>_<shot>/`.
- `OB_LOOK='{"ev100": 12.0, "sun_yaw": 40}'` overrides the look values (see `LOOK_DEFAULTS` in
  `build_city_level.py`). `OB_CITY_ONLY=look tools/city/ue.sh tools/city/build_city_level.py`
  re-lights the saved level without a full rebuild.
- `OB_CITY_SKIP=buildings,scatter` leaves the buildings or dressing out for fast look-dev.
- `OB_EXTRA` sets the rider arguments. For OB_CityHill use:
  `OB_EXTRA="-ObRenderRider -ObRiderLights -ObKeyCd=20000 -ObRimCd=40000"`.

## The steps

| Step | Script | Runs in | Does |
|---|---|---|---|
| 1 | `measure_buildings.py` | editor, offscreen | Logs each building's measured bounds (footprint) |
| 2 | `gen_city.py` | numpy | The street, cross street, kerbs, sidewalks (exact course heights), the massing layer and every scatter transform |
| 3 | `tools/trail/gen_track.py` or a MuJoCo npz | numpy | The ride; `tools/replay/npz_replay.py --bin` writes the replay file |
| 4 | `tools/render/plan_cameras.py --shots follow` | numpy | One follow shot over the whole run (do NOT edit this file) |
| 5 | `build_city_level.py` | editor, offscreen (`ue.sh`) | Materials, meshes, buildings and plinths, dressing, look, sequence, MRQ configs |
| 6 | `verify_city.py` | editor, offscreen | The tyre against the street along the track; writes `/tmp/ob-city/verify.txt` |

The editor steps run in the full editor with `-RenderOffscreen`, because a commandlet compiles no
material shaders and so cannot report a material compile error. `ue.sh` waits for the result file
and stops the editor if it hangs while it shuts down.

The C++ helpers (`Source/OverboardGame/*/Trail*`) are shared with OB_Trail:
`UTrailBuildLibrary::CreateStaticMeshFromObm` makes the street/kerb/sidewalk meshes from the OBM1
files (`tools/trail/obm.py`), with complex-as-simple collision so `verify_city.py` can trace onto
them. `ATrailScatterActor` holds the street dressing as one HISM component per kind.

## The course is the shape

- Frames: ABoardActor maps MuJoCo `(x, y, z)` m to Unreal `(100x, -100y, 100z)` cm. OB_CityHill puts
  the PlayerStart `OB_CityHillOrigin` at the world origin with yaw 0, so the MuJoCo origin is the world
  origin. The street runs along MuJoCo -X; the rider travels -X.
- The street, the kerbs (0.15 m) and the sidewalks (3.5 m) are exact meshes sampled from
  `course_height.npy`, as the OB_Trail asphalt is. The heightfield already carries the crown, the
  kerb step and the flat sidewalk shelf; `gen_city.py` reads them straight off it.
- The street mesh sits `ribbon_lift_m` (4 mm) above the course height, so the tyre clears it by a
  few mm. `verify_city.py` confirms the gap.
- The cross street is flat at the valley floor and sits a little higher than the main street, so it
  reads on top in the intersection box.

## Buildings

Buildings line both sides, set back at the sidewalk's outer edge (9.65 m from the centre line), with
the facade toward the street. On the slope each building stands at its uphill front corner height and
gets a concrete plinth (an engine cube, `M_CityPlinth`) that fills down to the downhill corner — the
San Francisco stepped look. A cheap massing layer (`massing.obm`, `M_CityMassing`, a window grid)
gives the far ends and the second row their skyline depth.

The front-row buildings are City Sample packed level actors (`BPP_*`). **A packed level actor does
not populate its instanced components after a headless python spawn**, so `measure_buildings.py`
cannot read its footprint; `build_city_level.py` falls back to a per-building footprint estimate for
the layout. The actor still builds its geometry in the `-game` render. See the traps below.

## Dressing and its sources

| Element | Source |
|---|---|
| Street | Megascans asphalt (City Sample), lane markings and crosswalks from the mesh UVs |
| Sidewalk / kerb / plinth | Megascans cast-in-situ concrete (City Sample) |
| Buildings | City Sample SF building kits: `Kit_Ref_Bldg` and `Kit_Hero_Bldg` |
| Street lamps | City Sample `Kit_StreetLamp_B` |
| Street trees + grates | City Sample `Kit_Tree_Maple_Red` + `Kit_TreeBase_A` |
| Bins / signs | City Sample `Kit_Trashcan_A`, `Kit_StopSign_A`, `Kit_StreetSign_A`, `Kit_BusStopSign_A` |

All dressing sits on the sidewalks (`|y| >= 6.15 m`), so the ridden street (`|y| < 1.6 m`) stays
clear. `gen_city.py` writes `scatter.json` in the trail's format, so `plan_cameras.py` tests camera
clearance against it (`OB_SCATTER`).

## Traps

- **Packed level actors do not populate headless.** `measure_buildings.py` reports a 16 cm default
  bound for a `BPP_*` actor spawned by python; the ISM components build only in `-game`/PIE. The
  build uses fallback footprints for the layout.
- **The street mesh is the collision surface.** `CreateStaticMeshFromObm` gives it complex-as-simple
  collision, so `verify_city.py` traces onto it; there is no landscape.
- **Manual exposure.** With no physical camera, `auto_exposure_bias` is minus the scene's EV100.
  Auto exposure gave white frames in the MRQ warm-up.
- **The builder must not open the City Park Showcase sublevel.** It starts from `OB_Main` and makes a
  fresh blank map, so Showcase is never loaded or saved.
