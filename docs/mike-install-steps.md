# Installs for Mike (needs the laptop)

These steps unblock the skater's look. Nothing else waits on them.

## 1. MetaHuman Creator Core Data (about 10 min)

It gives real skin, eyebrows and the Creator wardrobe.

1. Quit the Unreal Editor.
2. Open the Epic Games Launcher. Go to Unreal Engine, then Library.
3. On the 5.7 tile, click the small arrow. Click Options.
4. Tick "MetaHuman Creator Core Data". Click Apply.
5. When the download is done, tell the render session "core data done".

## 2. A skater outfit: hoodie and sneakers (about 10 min)

City Sample has no hoodie or sneakers, so the outfit comes from Fab.

1. Open `/Users/mike/projects/overboard-game-render/OverboardGame.uproject` in UE 5.7.
2. Open Window, then Fab. Sign in if it asks.
3. Search "NDart Urban Casual Outfit for MetaHuman" (a hoodie, casual jeans, high-top sneakers;
   a parametric wardrobe, so it fits his body). Click Add to Project.
   Second choice: "MetaOutfits Street Wear Urban Casual" (low-top sneakers) and a MetaHuman hoodie.
   The item must say MetaHuman compatible.
4. Close the editor. Do not save a level.
5. Tell the render session "outfit done".

## 3. Optional, low priority: nature packs for the valley level

Only for the valley (OB_Trail). The city comes first. In the same Fab window, add Megascans
"forest floor", "leaf litter", "fallen log", "tree stump", "river stones", "mossy boulder", and one
broadleaf tree set (European beech, hornbeam or black alder).
